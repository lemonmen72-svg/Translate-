# Офлайн-переводчик поверх медиа других приложений (Android)

Приложение для Android, которое запускается поверх других приложений,
захватывает системный звук, распознаёт речь, переводит на русский и показывает
субтитры поверх исходного приложения.

Исходные языки: русский, английский, китайский, японский — выбираются заранее,
без автоопределения. Целевой язык всегда русский.

## Состояние

Код написан целиком: захват, VAD, распознавание, фильтр галлюцинаций, перевод,
оверлей, foreground service, интерфейс, троттлинг, озвучка.

**Но ни разу не запускался на устройстве.** Среда разработки — контейнер без
Android и без доступа к `dl.google.com`, поэтому APK собирается в GitHub Actions,
и там проверяется только компиляция. Захват звука, работа VAD на реальном
контенте, качество распознавания, фактическая задержка, поведение оверлея —
не проверены. Первая сессия на телефоне и есть первая проверка.

Чтобы это можно было измерить, а не угадывать, в истории под каждой фразой
показывается разбивка по стадиям: сколько ушло на ASR, на перевод, на остальное.

## Установка

APK лежит в релизе `apk-latest` и обновляется каждой сборкой ветки:

**[OverlayTranslator-debug.apk](https://github.com/lemonmen72-svg/Translate-/releases/download/apk-latest/OverlayTranslator-debug.apk)** — около 85 МБ, только arm64.

1. Скачать по ссылке выше (можно прямо на телефоне) и установить, разрешив
   установку из неизвестных источников.
2. Выдать разрешение «Поверх других приложений» — кнопка в приложении откроет
   нужный экран настроек.
3. Выбрать исходный язык и профиль, нажать «Запустить сессию» и согласиться на
   захват звука.

Модели скачиваются при первом запуске сессии из релиза `models-v1`: около 104 МБ
для профиля «Скорость», 161 МБ для «Баланса», 376 МБ для «Качества». Плюс модель
перевода — она у бэкенда «Быстрый» качается средствами ML Kit, у «Точного»
примерно 145 МБ на направление из того же релиза.

Минимальная версия Android — 10 (API 29): раньше не существовало
`AudioPlaybackCaptureConfiguration`. Профиль «Качество» рассчитан на 6+ ГБ RAM.

## Как это устроено

```
MediaProjection → AudioRecord (16 кГц моно)
      → Silero VAD (нарезка на фразы)
      → [опц.] GTCRN (шумоподавление)
      → Whisper (forced language, без conditioning на историю)
      → фильтр галлюцинаций
      → [опц.] восстановление пунктуации
      → перевод (ML Kit или Opus-MT в ONNX; для русского — пропуск)
      → оверлей с субтитрами
      → [опц.] системный русский TTS (захват на это время приостановлен)
```

Между VAD и распознаванием стоит слот на одну фразу с вытеснением старой. Без
этого на длинной речи задержка растёт неограниченно: ASR не успевает за реальным
временем, очередь копится, и через минуту субтитры отстают на полминуты.
Сброшенные фразы считаются и показываются.

## Где реализация отходит от ТЗ

Каждое решение объяснено в [`docs/04-implementation.md`](docs/04-implementation.md).

- **Перевод по умолчанию — ML Kit, а не NLLB-600M.** NLLB один съедает весь
  бюджет задержки (около 2 с на фразу). Opus-MT в ONNX доступен как режим
  точности — там ja→ru идёт напрямую, без английского посредника.
- **Для русского перевода нет вовсе** — целевой язык совпадает с исходным.
- **Уверенность ASR недоступна.** sherpa-onnx не отдаёт `avg_logprob` и
  `no_speech_prob`, поэтому фильтр галлюцинаций построен на коэффициенте сжатия
  gzip, повторах, скорости речи и списке типовых фраз Whisper.
- **Контекст предыдущих фраз** нельзя передать ни в ML Kit, ни в обычный
  Opus-MT. Вместо имитации сделана опция «склеивать обрывки фраз».
- **GTCRN вместо RNNoise**, и опцией: RNNoise рассчитан на стационарный шум, а
  музыка нестационарна. На музыке лёгкий денойз может и ухудшить результат.
- **Озвучка системным TTS**, а не Silero (лицензия CC BY-NC) и не Piper
  (требует каталог espeak-ng-data).
- **zh→ru прямой модели Opus-MT нет** — в режиме точности китайский идёт
  zh→en→ru.

## Юридический момент

Захват системного аудио сторонних приложений может нарушать их условия
использования. Приложение сделано для личного использования и не предназначено
для публикации в Play Store: Google отклоняет приложения с MediaProjection для
захвата чужого аудио.
