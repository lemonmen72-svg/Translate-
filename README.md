# Офлайн-переводчик поверх медиа других приложений (Android)

Приложение для Android, которое запускается поверх других приложений,
захватывает системный звук, распознаёт речь, переводит на русский и показывает
субтитры поверх исходного приложения. Полностью офлайн, без сторонних серверов.

Исходные языки: русский, английский, китайский, японский (выбираются заранее,
без автоопределения). Целевой язык — всегда русский.

## Текущее состояние

**Стадия изучения. Кода приложения ещё нет.** Готова проработка ТЗ:
проверены допущения, найдены расхождения, зафиксирована архитектура и план.

## Главное из разбора

1. **База — sherpa-onnx**, а не сборка из четырёх независимых частей. Один
   рантайм onnxruntime закрывает VAD, ASR, TTS, восстановление пунктуации и
   шумоподавление. Два пункта из «дополнительных задач» ТЗ там уже готовы.
2. **Заявленная задержка 1.5–3 с несовместима с базовым набором моделей из ТЗ.**
   Whisper-Small + NLLB-600M дают реалистично 4–6 с. В 1.5–3 с укладывается
   только tiny/base ASR + компактная MT класса Opus-MT.
3. **Прямой модели zh→ru у Opus-MT, похоже, нет** — дырка в плане, требует
   решения до реализации MT.
4. **При исходном русском MT не нужен вовсе** — отдельная быстрая ветка.
5. **Контекст предыдущих фраз — только в MT, никогда в декодере ASR**, иначе
   включается механизм самоподдерживающихся галлюцинаций Whisper.
6. **RNNoise против музыкального фона почти бесполезен** — он для стационарного
   шума. Вместо него GTCRN, и то опционально, после замера WER.
7. **TTS создаёт петлю обратной связи** — собственный русский голос попадает в
   тот же захват аудио. В ТЗ это не учтено.
8. **Ограничения MediaProjection на Android 14/15 жёстче**, чем в ТЗ: согласие
   на каждую сессию, запрет кэширования Intent, строгий порядок вызовов. Значит
   «включил и забыл» невозможно — это меняет UX.
9. **Нужен back-pressure с drop-oldest** — иначе задержка растёт неограниченно
   на длинной речи.

Подробности и источники — в [`docs/01-research.md`](docs/01-research.md).

## Юридический момент

Захват системного аудио сторонних приложений может нарушать их условия
использования. Приложение делается строго для личного использования и не
предназначено для публикации в Play Store.
